# Голосовой тренажёр технического интервью

SmartApp для устройств Сбера (SberBox, SberPortal, Салют) — голосовой тренажёр технических вопросов для Data Science-специалистов.

Пользователь голосом выбирает тему, проходит 5 вопросов с фидбеком от LLM, в конце получает радар-чарт с оценками по всем темам.

## Как это устроено

```
Голос пользователя
       │
       ▼
 .sc-сценарии (SmartApp Code, серверы Сбера)
 — тонкий NLU-слой: распознаёт команды и передаёт их в React
       │
       ▼
 React-приложение (CanvasApp, localhost:3000)
 — управляет состоянием, отображает вопросы и результаты
       │
       ▼
 FastAPI-бэкенд (localhost:8000)
 — управляет сессиями, вызывает LLM через GigaChat
       │
       ▼
 LLM (GigaChat, Sber)
 — оценивает ответ, генерирует фидбек и следующий вопрос
```

Голосовые фрагменты накапливаются в буфере. Команда «готово» отправляет весь накопленный ответ на оценку. После 5 вопросов — радар-чарт с оценками по каждой теме (0–10).

## Предварительные требования

- **Node.js** 18+ (рекомендуется `nvm`)
- **yarn** (`npm install -g yarn`)
- **Python** 3.11+
- Аккаунт в [SmartApp Studio](https://developers.sber.ru/studio/) (для голосовой интеграции)
- Доступ к **GigaChat API** (для LLM) — авторизационные данные из [GigaChat Studio](https://developers.sber.ru/studio/)

## Настройка окружения

Конфиги разнесены: фронт и бэк читают **свои** `.env`-файлы.

### Корневой `.env` — только фронт (CRA)

```bash
cp .env.sample .env
```

```dotenv
# SmartApp Studio → Профиль → Настройки сервисов → Auth Token
REACT_APP_TOKEN=""

# Название CanvasApp из SmartApp Studio (фраза запуска)
REACT_APP_SMARTAPP=""

# URL бэкенда (по умолчанию локальный)
REACT_APP_BACKEND_URL=http://localhost:8000

# Опционально: запретить автооткрытие браузера
BROWSER=none
```

### `backend/.env` — только бэкенд

```bash
cp backend/.env.example backend/.env
```

```dotenv
# GigaChat API: base64(Client_ID:Client_Secret) из GigaChat Studio
GIGACHAT_AUTH_KEY=""

# Модель GigaChat (GigaChat | GigaChat-Pro | GigaChat-Max)
GIGACHAT_MODEL=GigaChat

# CORS: откуда фронту разрешено стучаться к бэку
CORS_ORIGINS=http://localhost:3000
```

После изменения `.env` требуется **полный перезапуск** соответствующего сервера (CRA/uvicorn).

## Запуск бэкенда

```bash
cd backend

```

Бэкенд поднимется на `http://localhost:8000`. Документация API: `http://localhost:8000/docs`.

## Настройка SmartApp Studio

Для работы голосового управления нужно создать два проекта в SmartApp Studio.

### 1. SmartApp Code (NLU-сценарии)

1. Открой [SmartApp Studio](https://developers.sber.ru/studio/) → «Создать проект»
2. Выбери **Code for SmartApp** (не «Code for SaluteBot»)
3. Создай пустой проект, дай название (например, «Тренажёр интервью»)
4. В проекте: «Настройки проекта» → «Экспорт/Импорт» → загрузи файл **`scenario-new.zip`** из корня репозитория
5. «Редактор» → «Сценарии» → нажми **«Собрать»**
6. «Публикации» → **«Получить вебхук»** — скопируй URL

### 2. CanvasApp (Frontend)

1. Снова «Создать проект» → раздел «Мини-приложения Салют» → **CanvasApp**
2. Название должно совпадать с тем, что записано в `REACT_APP_SMARTAPP` в `.env`
3. Укажи ту же группу проекта, что и у SmartApp Code
4. «Параметры» → «Сценарий смартаппа»:
   - Тип сценария: **SmartApp Code API**
   - Внешняя ссылка: вставь URL вебхука из шага выше
5. Сохрани

### 3. Токен для локальной разработки

1. SmartApp Studio → Профиль (правый верхний угол) → «Настройки профиля»
2. «Настройки сервисов» → «SmartApp» → вкладка «Эмулятор»
3. «Обновить ключ» → «Скопировать ключ»
4. Вставь в `.env` в переменную `REACT_APP_TOKEN`

## Голосовые команды

### Экран выбора темы

| Команда | Действие |
|---------|---------|
| «Python» / «первый» | Начать интервью по Python |
| «Classical ML» / «второй» | Начать интервью по Classical ML |
| «Deep Learning» / «третий» | Начать интервью по Deep Learning |
| «NLP» / «четвёртый» | Начать интервью по NLP и CV |

### Во время интервью

| Команда | Действие |
|---------|---------|
| _(любой текст)_ | Фрагмент накапливается в буфере ответа |
| «готово» | Отправить накопленный ответ на оценку |
| «дальше» / «следующий» / «пропустить» | Пропустить вопрос |
| «сдаюсь» / «не знаю» / «пас» | Пропустить с нулевой оценкой |
| «закончить» / «завершить» / «хватит» | Завершить тему досрочно и показать результаты |
| «покажи результаты» / «итоги» | Завершить тему и показать радар-чарт |

Ответ можно произносить несколькими репликами — они склеиваются. Команда «готово» отправляет всё накопленное.

## API-эндпоинты бэкенда

Все эндпоинты принимают и возвращают JSON.

### `POST /start`

Начать сессию по теме.

```json
// Запрос
{ "session_id": "uuid", "topic": "python" }

// Ответ
{ "question": "Что такое GIL в Python...", "pronounce_text": "..." }
```

### `POST /evaluate`

Оценить ответ пользователя.

```json
// Запрос
{ "session_id": "uuid", "text": "GIL это..." }

// Ответ
{
  "action": "NEXT_QUESTION",   // NEXT_QUESTION | CONTINUE | TOPIC_COMPLETE | ERROR
  "feedback": "Верно! ...",
  "next_question": "Объясни разницу между...",
  "question_index": 2,
  "final_scores": null
}
```

`TOPIC_COMPLETE` содержит `final_scores` — словарь `{topic: score | null}` для всех 4 тем.

### `POST /skip`

Пропустить текущий вопрос без оценки.

```json
// Запрос
{ "session_id": "uuid" }
```

### `POST /finish`

Завершить тему досрочно (фиксирует баллы за пройденные вопросы).

```json
// Запрос
{ "session_id": "uuid" }
```

## Устранение проблем

### Приложение запускается, но ассистент не работает

- Проверь, что `REACT_APP_TOKEN` и `REACT_APP_SMARTAPP` заполнены в `.env`
- После изменения `.env` нужен полный перезапуск (`Ctrl+C` → `yarn start`)
- В dev-режиме в браузере нужно разрешить доступ к микрофону

### Бэкенд возвращает ошибку LLM

- Проверь `GIGACHAT_AUTH_KEY` в `.env` (это `base64(Client_ID:Client_Secret)`, а не сам Client_ID)
- Убедись, что значение `GIGACHAT_MODEL` доступно на твоём тарифе GigaChat (`GigaChat`, `GigaChat-Pro`, `GigaChat-Max`)
- Если в логах `SSL: CERTIFICATE_VERIFY_FAILED` — это ожидаемо: GigaChat использует российский CA, в коде `httpx.AsyncClient(verify=False)` это уже учтено

### `npm install` завершается ошибкой про typescript

Используй yarn или флаг `--force`:

```bash
yarn
# или
npm install --force
```

### Много предупреждений `Failed to parse source map`

Не ошибка, можно подавить добавив в `.env`:
```dotenv
GENERATE_SOURCEMAP=false
```

### Звук TTS не воспроизводится сразу после загрузки

В настройках сайта в браузере для `localhost` измени значение **Sound** с «Automatic» на «Allow».
