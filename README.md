# Голосовой квиз по Data Science

SmartApp для устройств Сбера (SberBox, SberPortal, Салют) — офлайн-квиз с multiple choice по DS-темам.

Пользователь голосом или кликом выбирает тему, длину прохождения и один из четырёх вариантов ответа на каждый вопрос. После каждого ответа сразу видно правильный вариант с пояснением. В конце — радар-чарт с долей правильных по темам.

## Как это устроено

```
Голос пользователя
       │
       ▼
 .sc-сценарии (SmartApp Code, серверы Сбера)
 — тонкий NLU-слой: распознаёт команды и передаёт их в React
       │
       ▼
 React-приложение (CanvasApp)
 — хранит state, банк вопросов, рисует экраны и подсветку
```

Бэкенда нет: банк вопросов и логика квиза — статика во фронте. Это нужно, чтобы приложение прошло модерацию SmartApp Studio.

## Темы

| ID | Название |
|----|----------|
| `python` | Python |
| `classical_ml` | Classical ML |
| `deep_learning` | Deep Learning |
| `nlp_cv` | NLP и Computer Vision |

На сессию пользователь выбирает длину: 5, 10, 20 вопросов или весь банк темы. Вопросы сэмплятся случайно (Fisher-Yates).

## Предварительные требования

- **Node.js** 18+ (рекомендуется `nvm`)
- **yarn** (`npm install -g yarn`)
- Аккаунт в [SmartApp Studio](https://developers.sber.ru/studio/) — для голосовой интеграции

## Настройка окружения

```bash
cp .env.sample .env
```

```dotenv
# SmartApp Studio → Профиль → Настройки сервисов → Auth Token
REACT_APP_TOKEN=""

# Название CanvasApp из SmartApp Studio (фраза запуска)
REACT_APP_SMARTAPP=""

# Опционально: запретить автооткрытие браузера
# BROWSER=none
```

После изменения `.env` нужен **полный перезапуск** dev-сервера.

## Запуск

```bash
yarn          # установить зависимости (один раз)
yarn start    # dev-сервер на localhost:3000
yarn build    # production-билд
yarn test --watchAll=false   # прогон тестов
```

В браузере откроется приложение с панелью ассистента (шарик внизу). В dev-режиме голосовые команды можно вводить текстом в строке рядом с шариком.

## Настройка SmartApp Studio

Нужны два проекта в SmartApp Studio.

### 1. SmartApp Code (NLU-сценарии)

1. [SmartApp Studio](https://developers.sber.ru/studio/) → «Создать проект»
2. **Code for SmartApp** (не «Code for SaluteBot»)
3. «Настройки проекта» → «Экспорт/Импорт» → загрузи **`scenario-new.zip`** из корня репозитория
4. «Редактор» → «Сценарии» → **«Собрать»**
5. «Публикации» → **«Получить вебхук»** — скопируй URL

### 2. CanvasApp (Frontend)

1. «Создать проект» → «Мини-приложения Салют» → **CanvasApp**
2. Название должно совпадать с `REACT_APP_SMARTAPP` в `.env`
3. Группа проекта — та же, что и у SmartApp Code
4. «Параметры» → «Сценарий смартаппа»:
   - Тип: **SmartApp Code API**
   - Внешняя ссылка: вебхук из шага 5 выше

### 3. Токен для локальной разработки

1. SmartApp Studio → Профиль → «Настройки профиля»
2. «Настройки сервисов» → «SmartApp» → «Эмулятор»
3. «Обновить ключ» → скопировать
4. Вставить в `.env` в `REACT_APP_TOKEN`

## Голосовые команды

### Welcome (выбор темы)

| Команда | Действие |
|---------|----------|
| «Python» / «первый» | Тема Python |
| «Classical ML» / «второй» | Тема Classical ML |
| «Deep Learning» / «третий» | Тема Deep Learning |
| «NLP» / «четвёртый» | Тема NLP и CV |

### LengthPick (длина прохождения)

| Команда | Действие |
|---------|----------|
| «пять» / «5 вопросов» | 5 вопросов |
| «десять» / «10 вопросов» | 10 вопросов |
| «двадцать» / «20 вопросов» | 20 вопросов |
| «весь банк» / «целиком» | Все вопросы темы |

### Quiz (выбор ответа)

| Команда | Действие |
|---------|----------|
| «первый» / «номер один» / «1» | Выбрать вариант 1 |
| «второй» / «вариант два» / «2» | Выбрать вариант 2 |
| «третий» / «3» | Выбрать вариант 3 |
| «четвёртый» / «4» | Выбрать вариант 4 |
| «не знаю» / «пропусти» | Засчитать вопрос как ошибочный, перейти к фидбеку |
| «закончить» / «хватит» | Досрочно завершить тему |

### Feedback (после ответа)

| Команда | Действие |
|---------|----------|
| «дальше» / «следующий» | Перейти к следующему вопросу |
| «закончить» | Досрочно завершить тему |

### Results

| Команда | Действие |
|---------|----------|
| «ещё одну тему» / «давай ещё» | Вернуться к welcome (радар сохраняется) |
| «начать заново» / «сначала» | Полный сброс радара |

## Устранение проблем

### Приложение запускается, но ассистент не работает

- `REACT_APP_TOKEN` и `REACT_APP_SMARTAPP` заполнены в `.env`?
- После правки `.env` нужен полный перезапуск (`Ctrl+C` → `yarn start`).
- В dev-режиме в браузере нужно разрешить доступ к микрофону.

### Голосовая команда не распознаётся

- Загрузи свежий `scenario-new.zip` в SmartApp Code и пересобери сценарий.
- Если фраза не в списке голосовых команд — добавь её в `smartapp-backend/src/sc/interview.sc` к нужному state и пересобери архив.

### Много предупреждений `Failed to parse source map`

В `.env`:
```dotenv
GENERATE_SOURCEMAP=false
```

### Звук TTS не воспроизводится сразу после загрузки

В настройках сайта в браузере для `localhost` измени **Sound** с «Automatic» на «Allow».
