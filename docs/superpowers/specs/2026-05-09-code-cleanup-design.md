# Чистка кода: дизайн

Дата: 2026-05-09
Статус: утверждён, готов к плану реализации

## Цель

Привести рабочий учебный проект (голосовой тренажёр интервью DS) к виду
человеческого, а не «нейроподобного» кода. Цель — чтобы при открытии файла не
бросалось в глаза, что код писал ассистент: осмысленные комментарии,
аккуратные типы, понятные имена и границы модулей.

Поведение приложения и сценариев Салюта **не меняется**. Все ручные сценарии,
которые сейчас работают, должны продолжать работать.

## Решения, принятые на этапе brainstorm

| Порядок работы | Послойно (backend → frontend → docs) и внутри каждого слоя — три прохода: формат/линт, типы+комменты, локальный рефакторинг. По коммиту на проход. |

## Тулинг

Добавляется:

- `backend/pyproject.toml` — конфиг `ruff`: `line-length = 100`, `target-version = "py311"`,
  правила `E,W,F,I,B,UP,SIM,RUF`.
- `.editorconfig` в корне — общие правила отступов и переводов строк для
  Python (4 пробела) и JS/JSX (2 пробела).

Не добавляется: pre-commit, husky, GitHub Actions, новые npm/pip-зависимости в
проектные манифесты. `ruff` запускается локально (через `pipx`/uv/`pip install`
в окружении разработчика), без фиксации в `requirements.txt`.

### Проход 3 — локальный рефакторинг

#### Backend

**`main.py` (401 строка) — слишком тяжёлый:**

1. **Pydantic-схемы запросов и ответов** в новый файл `backend/schemas.py`.
   Сейчас тела разбираются вручную (`body = await request.json(); session_id: str = body["session_id"]`)
   — это и не FastAPI-way, и без валидации. После: `async def evaluate(req: EvaluateRequest)`.
   Эндпоинты становятся короче, ошибки 422 возвращаются автоматом.

2. **Конфиг логирования** в новый файл `backend/logging_config.py` (формат,
   handler, функция `setup_logging()`). Из `main.py` уходит ~15 строк.

3. **Хелпер «продвинуть вопрос или финализировать тему»** — внутри `/evaluate`
   60 строк ветвлений `if session.question_index >= 5 ... else ...`.
   Извлечь в приватный хелпер `_advance_or_finalize(...)` в том же `main.py`
   (без перехода на роутеры).

`_build_final_scores` оставить в `main.py` (мелкий, специфичный для эндпоинтов).

**`llm_service.py` (282 строки):** только типы и докстринги, структура нормальная.

**`session_manager.py` (87 строк):** заменить устаревший `datetime.utcnow()`
на `datetime.now(UTC)` (deprecated в 3.12+). Технический долг, лучше
исправить попутно. Проверить тесты на работу с timezone-aware datetime.

**`questions.py`:** только данные — оставить как есть.

#### Frontend

**`App.jsx` (335 строк) — два извлечения:**

1. **`src/services/assistant.js`** — голая интеграция с Салютом:
   - `createAssistantInstance(getState)` (бывший `initializeAssistant`)
   - `speak(assistant, text)` — обёртка над `sendData({ action: SPEAK })` с
     dev-фоллбеком на `window.speechSynthesis`.
   - Без React. Класс `App` импортирует и использует.

2. **`src/services/evaluationDispatch.js`** — чистая функция:
   - `decodeEvaluateResponse(data, currentTopic) → { stateUpdate, speechText }`
   - Сейчас это `_handleEvaluateResponse` внутри класса с тремя ветками и
     `setState` внутри. Чистая функция читается проще, и класс просто
     `setState(stateUpdate); speak(speechText)`.

**Внутри `App.jsx`:**
- Убрать дебажные `console.log('constructor')`, `console.log('render')`,
  `console.log('componentDidMount')` и пустой `componentDidMount`.
- Слить три похожих async-обработчика
  (`handleFinishAnswer`/`handleNextQuestion`/`handleFinishInterview`)
  через мини-хелпер общим `setLoading + try/catch`.
- Подсократить `assistant.on(...)`-логи: оставить `error` (через `console.warn`),
  остальные убрать.

**Прочее:**
- `interviewApi.js` — JSDoc-типы для возвращаемых форм; функции не трогаем.
- `views/InterviewView.jsx`, `views/WelcomeView.jsx` — только косметика и
  русские комменты. Стили (`styled-components`) оставить как есть.
- `views/ResultView.jsx` — если конфиг радар-чарта разросся, унести в
  `src/constants/chartConfig.js`. Решить по факту.

## Риски

1. **TTS в проде через `assistant.sendData`.** Внутри `_speak` используется
   `unsubscribe`-callback. При переносе/переименовании легко получить молчаливый
   отвал озвучки в проде. Митигация: пройти dev-режим (там `speechSynthesis`),
   код-ревью переноса вручную сравнить со старой версией строкой в строку.

2. **Pydantic-схемы могут стать строже текущего поведения.** Например, если
   фронт шлёт пустой `text`, сейчас просто пройдёт; после — 422. Митигация:
   разумные значения по умолчанию, не делать поля строже текущего фактического
   поведения.

3. **Замена `datetime.utcnow()` → `datetime.now(UTC)`** даёт timezone-aware
   datetime, что может ломать сериализацию или тесты, если они проверяют
   ровный формат без `+00:00`. Митигация: прогнать тесты, при необходимости
   привести к ISO-string или `.replace(tzinfo=None)` для логов.
